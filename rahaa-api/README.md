# منصة راحة للنقل الذكي - Backend (Laravel REST API)

مشروع الخادم الخلفي المتكامل لمنصة **راحة (Rahaa Smart Mobility)**، مبني وفق أحدث معايير إطار العمل **Laravel** ومربوط بقاعدة بيانات فعلية مع توفير نظام مصادقة آمن وتوثيق وحماية كاملة لجميع المسارات.

---

## 1. متطلبات التشغيل

- **PHP**: الإصدار `^8.2` (مع تفعيل الامتدادات: `pdo_sqlite`, `sqlite3`, `curl`, `mbstring`, `fileinfo`, `openssl`).
- **Composer**: الإصدار `^2.0`.
- **Node.js & npm**: لتشغيل واجهة الـ Frontend (React + Vite).
- **قاعدة البيانات**: SQLite افتراضياً (أو MySQL عبر تعديل `.env`).

---

## 2. التثبيت والإعداد السريع

### أ) إعداد الـ Backend (Laravel API)

1. الانتقال لمجلد الـ Backend:
   ```bash
   cd "d:\Flutter projcts\ali\rahaa-api"
   ```

2. نسخ ملف البيئة وتوليد المفتاح:
   ```bash
   copy .env.example .env
   php artisan key:generate
   ```

3. تشغيل ملفات التهجير وبذور البيانات (Migrations & Seeders):
   ```bash
   php artisan migrate:fresh --seed
   ```

4. ربط مجلد الملفات المرفوعة:
   ```bash
   php artisan storage:link
   ```

5. تشغيل سيرفر Laravel:
   ```bash
   php artisan serve --host=127.0.0.1 --port=8000
   ```

## 3. حساب المشرف الإداري الأساسي

تم إنشاء حساب المشرف الإداري تلقائياً عبر `AdminSeeder`:

- **اسم المستخدم:** `علي نشوان`
- **كلمة المرور الأولية:** `12345`
- **الدور:** `Admin`

> **تنبيه أمني هام:** كلمة المرور `12345` هي كلمة مرور أولية مخصصة للتهيئة الأولية، **ويجب تغييرها فوراً** قبل إطلاق النظام في بيئة الإنتاج.

---

## 4. آلية تغيير كلمة مرور المشرف الإداري

- **الواجهة:** تم حذف خيار «نسيت كلمة المرور؟» من شاشة دخول المشرف الإداري منعاً لأي استغلال.
- **طريقة التغيير:** يتم تغيير كلمة المرور حصراً من **داخل لوحة المشرف الإداري** بعد تسجيل الدخول بنجاح، عبر الانتقال إلى:
  `لوحة الإدارة -> إعدادات النظام -> بطاقة "تغيير كلمة مرور المشرف الإداري"`.
- **الحقول المطلوبة:**
  1. كلمة المرور الحالية.
  2. كلمة المرور الجديدة.
  3. تأكيد كلمة المرور الجديدة.
- **الأمان في الخادم:** التحقق من جلسة الـ Admin، ومطابقة `Hash::check()` لكلمة المرور الحالية، وحفظ الكلمة الجديدة بـ `Hash::make()`، وإبطال الرموز السابقة وتسجيل العملية في `admin_logs`.

---

## 5. استعادة كلمة مرور الراكب والسائق عبر SMS

تتوفر خدمة **«نسيت كلمة المرور؟»** فقط لحسابات الركاب والسائقين في شاشة الدخول:
1. إدخال رقم الهاتف المسجل.
2. التحقق من الرقم وإرسال رمز تحقق عشوائي آمن (6 أرقام) عبر SMS مزود حقيقي، مع حماية Rate Limiting (حد أقصى 3 محاولات لكل 10 دقائق).
3. إدخال وتأكيد رمز الـ SMS مع فحص الصلاحية الزمنية (10 دقائق) وحد المحاولات (5 محاولات كحد أقصى).
4. تعيين كلمة المرور الجديدة وتشفيرها.

> **ملاحظة حول مزود الـ SMS:**
> في حال عدم ضبط مفاتيح الـ SMS في ملف `.env` (`SMS_PROVIDER`, `SMS_API_KEY`)، يُرجع الخادم رسالة خطأ واضحة تفيد بأن الخدمة غير مهيأة، ولا يتم توليد رموز وهمية أو تجاوز التحقق كما تنص التعليمات.

## 6. مسارات الـ API الرئيسية (Endpoints)

| الطريقة | المسار | الوصف | الصلاحية |
|---|---|---|---|
| `POST` | `/api/auth/login` | تسجيل الدخول (مشرف بالاسم، راكب/سائق بالهاتف) | عام |
| `POST` | `/api/auth/register/passenger` | تسجيل راكب جديد وحفظه | عام |
| `POST` | `/api/auth/register/driver` | تسجيل سائق جديد ورفع الوثائق (حالة `pending`) | عام |
| `POST` | `/api/auth/password-reset/sms/request` | طلب رمز استعادة عبر SMS | عام |
| `POST` | `/api/auth/password-reset/sms/verify` | التحقق من رمز SMS | عام |
| `POST` | `/api/auth/password-reset/sms/reset` | تعيين كلمة المرور الجديدة | عام |
| `GET`  | `/api/auth/me` | استرجاع بيانات المستخدم الحالي | Sanctum Token |
| `POST` | `/api/auth/logout` | تسجيل الخروج وإبطال الرموز | Sanctum Token |
| `POST` | `/api/admin/change-password` | تغيير كلمة مرور المشرف | Admin فقط |
| `GET`  | `/api/admin/stats` | إحصائيات لوحة التحكم | Admin فقط |
| `GET`  | `/api/admin/drivers` | استعراض السائقين وتدقيق وثائقهم | Admin فقط |
| `POST` | `/api/admin/drivers/{id}/approve` | اعتماد السائق وتفعيل حسابه | Admin فقط |
| `POST` | `/api/admin/drivers/{id}/reject` | رفض طلب السائق مع ذكر السبب | Admin فقط |
| `POST` | `/api/trips/request` | طلب رحلة جديدة | Passenger |
| `GET`  | `/api/trips/available` | عرض الرحلات المتاحة | Driver معتمد |
| `POST` | `/api/trips/{id}/accept` | قبول الرحلة (مع قفل التزامن لمنع التضارب) | Driver معتمد |
